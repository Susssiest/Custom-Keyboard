**Project Writeup**

I am completely new to KiCad, but this project was a lot of fun for me and definitely an amazing first PCB project. My goals changed a little throughout the process, but I’m really happy with how it turned out. The keyboard is essentially a 60% layout with an additional row on top featuring rotary encoders, rocker/toggle switches, and an OLED screen. I ran into a few problems when I first started, but I quickly got the hang of KiCad and really enjoyed designing the PCB. Throughout the project, I learned a lot and improved my skills in PCB routing, schematic design, and BOM creation. I’m really looking forward to assembling the keyboard and seeing the finished product come together!
